🎮 Como Jogar o Super Trunfo (Nível Mestre)
Este programa permite simular um duelo entre duas cidades cadastradas através de uma comparação de atributos múltiplos.
1. Cadastro: O usuário deve inserir os dados de duas cartas (Cidade 1 e Cidade 2). O sistema calculará automaticamente a Densidade Populacional e o PIB per Capita.
2. Escolha de Atributos:
• O jogador escolhe o Primeiro Atributo para a disputa (ex: População ou PIB).
• O sistema exibirá um menu dinâmico para o Segundo Atributo, ocultando a opção já escolhida para garantir que a comparação seja feita com dados diferentes.
3. Duelo e Soma:
• O sistema recupera os valores dos dois atributos escolhidos para cada carta.
• É realizada a soma dos dois valores para cada cidade.
4. Veredito:
• A cidade que obtiver a maior soma total vence o duelo.
• Caso as somas sejam iguais, o sistema declarará Empate.
